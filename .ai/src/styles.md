# styles.css

> Last updated: 2026-06-09 | Protection: STANDARD

## Purpose

Defines the static visual presentation, paper preview, control panel, and print styles for the quote cloud.

## What It Does

- Styles the page shell and virtual paper board.
- Styles static quote text and optional author text.
- Styles basic controls.
- Defines print rules that hide controls and remove decorative effects.

## Important Notes / NEVER Change

- No hover transitions, focus animations, glows, or quote interactions.
- Print output must be white background with high contrast dark text.
- Do not override quote transforms in print; transforms are part of the layout coordinates.
